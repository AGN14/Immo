# docs

Documentation et matériel de référence. **Rien ici n'est compilé ni servi par l'application.**

## `reference-vestia/`

Maquettes HTML statiques d'une itération antérieure du produit, alors nommée « Vestia ».
Quatorze pages autonomes (landing, tarifs, dashboard, biens, locataires, loyers, quittance,
interventions, documents…) plus `PRODUCT.md`, le cahier de charges d'origine : cible béninoise,
F CFA, Mobile Money, direction visuelle « L'Atelier de Cotonou ».

Ces fichiers ne sont importés par aucun module et n'ont aucune dépendance sur le projet.
Ils servent de référence produit et visuelle — ouvrez-les directement dans un navigateur.

L'application Next.js s'en est écartée sur plusieurs points : nom (Immo), marché élargi
(Dakar, Abidjan, Douala, Cotonou), typographie (Source Serif 4 + Inter) et palette actuelle.
En cas de divergence, **c'est le code de `src/` qui fait foi**, pas ces maquettes.
